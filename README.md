# SahabatCare

Prototype web interaktif untuk inovasi **SahabatCare — Platform Telekonsultasi dan Dukungan Psikologis yang Aksesibel untuk Atlet Difabel**.

## Fitur yang aktif
- Navigasi single-page yang benar-benar berpindah halaman.
- SahabatAI dengan 12+ quick prompts khusus konteks atlet difabel.
- Input chat bebas + respons simulasi berbasis kata kunci.
- Well-being check-in 4 langkah.
- Riwayat check-in tersimpan di browser dengan localStorage.
- Pilihan konsultasi Chat, Voice Call, dan Video Call dalam alur simulasi.
- Accessibility Center: teks besar, kontras tinggi, dan gerakan minimal.
- Pengaturan tersimpan lokal.
- Tombol bantuan segera dengan jalur dukungan profesional.
- Responsive untuk laptop dan HP.

## Catatan
Ini adalah **prototype front-end**. SahabatAI bukan alat diagnosis dan konsultasi profesional di dalam prototype belum terhubung ke psikolog nyata atau backend.

## Menjalankan
Cukup buka `index.html`, atau aktifkan GitHub Pages dari branch `main` dan folder root.
